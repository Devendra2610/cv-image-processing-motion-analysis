6. Technical Conclusion

The experimental results confirm that:

  1. Median filtering is dramatically superior to linear Gaussian filtering for impulsive salt-and-pepper noise (36.85 dB vs 29.45 dB).
  2. Marker-controlled watershed successfully mitigates classical oversegmentation.
  3. SIFT demonstrates robust rotational invariance (65.43% match retention) and scale tolerance.
  4. Deep learning (YOLOv8) provides generalized semantic representations invariant to pose and orientation, whereas Viola-Jones is strictly axis-aligned.
  5. GMM background subtraction produces clean segmentation masks, while Lucas-Kanade optical flow computes continuous kinematic velocity vectors.
